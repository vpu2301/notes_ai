The query probe seeded rows inside a transaction that was rolled back
(nothing persisted) and timed the exact statement of
`generation_repository.items_for_note`, with and without `current_only`.

**What the extra calls cost.** Compared with Q1, a generation now makes: one
classify call (only when neither the author nor the template chose a type),
one title call (ADR-0059, only while `title_source = default`), a strict
retry of the summary when more than 30 % of its sentences fail the support
gate, a quote-reminder retry of a window that answered with line numbers,
and — off by default — one entity call. When the staging run exceeds the
+30 % guardrail, the candidates in order are: strict-retry rate, entity
tier, classify (the failure-scenario order in the sprint).
