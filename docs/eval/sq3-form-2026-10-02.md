# SQ3 — reads like a note: participants, rendering, filler, title (2026-10-02)

**Sprint:** SQ3. **Verdict:** the parts code can prove are met:

- nothing renders as a transcript turn;
- no speaker label in prose;
- bullets in recording order;
- one writer for who speaks;
- a title read from the whole recording.

Filler and redundancy improved but do not meet their gates. The blind rubric (T5) and the
participant gates could not run, because there are no raters and no participant gold. The rater

**Unsupported and recall** moved outside ±0.02 in a single run each. Two identical runs differ by

recall. One measurement here cannot separate that from noise.

## What was built

| Task | Change |
|---|---|
| T1 | A certainty word opens a paragraph with a dash ("Vorwurf — …"); bullets keep the colon. Lint rule `form.paragraph_colon_prefix` (D-FORM) repairs any paragraph shaped like a turn. The F3 presenter and guest lines ("Gast: X", "Präsentiert von: …") are no longer written. Web: `RichText` takes `allowSpeakerTurns`, false for generated sections (a `gen:` key or a section holding this generation's rows; no new route); the `SPEAKER` regex is unchanged. macOS and iOS renderers have no speaker rule for note text; tests in both prove certainty words and legacy guest lines stay text |
| T2 | `compose.speakers_of` is the single writer of who speaks. It lists every voice with ≥ 5 % of the speech or a role, by rank (host/narrator, expert, guest, interviewee, participant), then share. Names come with role and organisation from the verified introduction. A voice nobody named is "eine weitere Person" (several: "2 weitere Personen"), never a label. New role `expert`: an introduction with an expert's role word. Action lines drop a default-label owner |
| T3 | `line.subset` (D-RED) removes a line whose words are a proper subset of another's. `orient.ladder_redundant` removes a composed "Zunächst — …" ladder that cites only bullet facts; a missing paragraph 2 is then not a fault. §7 across orientation and sections: a summary sentence repeating a bullet removes the bullet when its section keeps two points, else the sentence. This replaces D1's exemption, which contradicted §7. A bullet that introduces a person precedes bullets naming them |
| T4 | The title is named after the pass, from excerpts of the opening, middle and end (the sampler already spread three; inspection fact 4 was out of date), plus the note's themes and its five most specific facts round-robin across thirds. Lint `title.generic` refuses a title of type words only ("Podcast-Folge"). Rater question "the title describes the whole recording" is on the rubric sheet and scored per arm |
| T5 | Not run (no raters). The pack is built locally (below) |

`PROMPT_VERSION` is 2026-10-01.3, for the title prompt, with a routing waiver.

**Order change worth knowing.** The title used to be set before extraction (Q6: classify → name →
extract), so a note had its name within seconds. It is now set after the pass, so the name arrives
with the note.

## T5 — the blind rubric

No ratings exist. The protocol needs three of six raters per note and ≥ 85 pairs, or 40 marked
directional. The corpus has 13 recordings, so even fully rated it is 13 pairs: directional at best.
The rater pack is built from these SQ3 pipeline notes and Mistral single-pass notes of the same
recordings:

```bash
# built (gitignored, holds transcripts): scripts/eval/local/sq3/rubric-2026-10-02/
#   n001.md … (one note per file, the transcript, the Q4 lines, the Q7 band, the title question)
#   rubric.csv      raters fill: q1…q8 (0–2) and title_whole (yes/no)
#   rubric_key.csv  kept apart: which arm each note is
uv run python scripts/eval/notes_pairs.py rubric-score <filled rubric.csv> <rubric_key.csv>
```

Without it, acceptance items 5 (raters' "whole recording" ≥ 90 %) and 6 (mean ≥ 13/16, Q4 = 2 on
≥ 95 %, ≥ 65 % vs single pass) stay open, and so does the kill rule (rubric < 11/16).
