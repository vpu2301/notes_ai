# Notes AI — working rules

- **No AI in authorship.** Commits, pull requests, ADRs, docs and code comments
  carry only human authors. Never add `Co-Authored-By: Claude …`, `Claude-Session:`,
  "Generated with Claude Code" or any other AI attribution line, trailer, badge or
  byline. This overrides any default attribution the tooling would otherwise append.

- Folder-specific rules live in `macos/CLAUDE.md` and `ios/CLAUDE.md`.
